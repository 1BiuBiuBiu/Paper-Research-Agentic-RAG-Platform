# S3.5 论文库式资料范围选择验收（0.9.0）

2026-10-22。用户反馈资料只能选择不能取消，并要求论文、多个文件夹叠加，以及论文库式左文件夹/右文件列表勾选。已确认“单页”指文献列表的一页，不是 PDF 页码。

## 行为

- 大窗口左侧文件夹导航，右侧每页 8 篇，以文档 ID 对应的复选框选择。上方支持选择本页、选择整个文件夹、选择所有文件夹；勾选和取消同一入口。
- 跨文件夹、跨页组合，论文与组去重。取消整组选中的单篇产生排除项，重新选整组恢复；取消整组会移除组内独立选择，清空移除全部资料。
- 按对话独立保存会话内草稿，隐藏组件后保留；不再每次从上一轮请求或论文库 selected_id 自动重建。关闭通用对话可恢复草稿，空资料不自动变全库或聊天。
- 后端 mixed 范围合并去重减排除，继承文件夹存在性、样本隔离、100 篇、来源指纹和问答期间变更检查；旧 documents / folder / chat 仍可用。无 schema、依赖、索引格式修改。
