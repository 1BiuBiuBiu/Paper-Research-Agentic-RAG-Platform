# S0 验收记录

日期：2026-10-20（Asia/Shanghai）。分支：feat/s0-paper-ingestion，上游基线 f165bf62ca6cf2df84ce0829f470823bdfa08bdd。

## 已实现

输入为文字型 PDF，FastAPI 验证上传/大小/页数并按内容哈希去重；Docling 子进程提取版面、清洗块、本文元数据、图区域/图注及正文关联；原文、版本化资产和 SQLite 持久化；Streamlit 提供原页/清洗对照、元数据修订、图文预览及 JIF 年份/来源录入。S0 未创建 embedding 或问答索引，文档状态为 parsed，health 中 rag_ready=false。

## 实际验证

- Ruff 检查与格式、mypy（28 个 S0 源文件）、compileall、uv pip check 与锁文件检查通过。
- RUN_DOCLING_TESTS=1 时最终 pytest 全套 **17 passed**，包括 16 项应用/提取边界测试和 1 项真实模型端到端解析测试；最终运行约 39 秒。默认快速运行 16 passed、1 skipped。Starlette TestClient 对 httpx 有一条弃用提示，测试仍通过，未为消除提示更换测试客户端。
- 真实 FastAPI 服务用实际 Docling 接收 3 页自建论文：status=parsed，2 张图，图片接口返回有效 PNG；该次 HTTP 入库约 120 秒，与另一真实解析进程并行。这是本机观测，不是性能承诺。
- Streamlit AppTest 对接真实 API：论文库、诊断及未启用问答页无异常；浏览器实际检查列表、原页/清洗文本、图与图注。
- Poppler 渲染并查看自建 PDF 首页：跨栏标题/摘要、两栏正文、脚注及页码清晰；浏览器核对图区域与图注。

## 公开论文补充检查

从 [arXiv 官方页面](https://arxiv.org/abs/1706.03762) 下载 v7 PDF，仅用于本机验证，未加入 Git。解析 15 页，标题 Attention Is All You Need、8 位作者、NIPS 2017 出版信息、原文摘要提取结果已断言通过。PDF 内未发现本文 DOI，保留空值，不以参考文献 DOI 替代或悄悄从网页回填。识别到 7 个候选图区域，区域数量不等同独立论文图数量，未宣称所有区域完美匹配。

首次样本暴露版权文字 journalistic 被误判为期刊、多位置文本未切 charspan 导致作者重复。通过实际输出及原页定位后修复词边界、出版信息来源和字符范围，重跑后 8 作者/会议年份检查通过。

首次模型下载在 Xet 通道没有进展，检查权重缓存仍为 0 字节后切换公开 HTTPS 下载，随后真实解析通过；没有关闭证书验证或购买服务。
