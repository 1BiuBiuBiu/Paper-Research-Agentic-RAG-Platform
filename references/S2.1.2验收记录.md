# S2.1.2 统一论文库与直接阅读

日期：2026-10-21。应用 0.3.2，分支 fix/s2-unified-library，基线 afaa4aa。

## 问题与处理

用户指出上一版拆成论文库 / 分类管理 / 文献文件夹多重入口，上传混在列表，导航稀疏，固定列宽 dataframe 的横向滚动条遮挡属性；点击论文还需要经过文件目录才能阅读。

- 当前只有一个论文库：左侧 200px 紧凑文件夹及同侧操作，右侧对应文献列表。取消独立分类管理页与文件目录中间页，删除 folder_contents UI 模块，运行论文目录不动。
- 左侧紧凑主导航含论文库 / Agent 平台 / 导入 / 设置；导入选择 PDF / 解析放在独立页面，列表不再有上传区域、大标题说明卡或进度 / 分页控件。
- 原生六列表自动换行，标题 / 作者 / 年份 / 期刊会议 / 页数 / 状态都在当前宽度内。标题和文件名不截断；没有 iframe / canvas 内的横向滚动条，长列表普通纵向滚动。
- 标题链接直接进入该文献 PDF 与解析对照，支持仅 PDF / 仅解析；返回保留分类搜索，侧栏切换文件夹清空阅读。图表、元数据、期刊指标仍按需选择。
- 分类仍为单归属；新建 / 改名 / 归档恢复在侧栏 popover，移动在整理 / 文献阅读中的操作里，可单篇或批量。没有复制 / 搬迁原 PDF / 解析 / 索引，也没有替用户分类。

## 数据与边界

- 沿用 SQLite schema v3、已有 API 与独立文档目录，无依赖升级。版本只修改根项目和 API 为 0.3.2。
- load_documents 在同一分类 / 搜索条件内读完 API 分页，以首次总数作为循环上限，空批次停止，按 ID 去重；不载入全库解析 / 向量。
- 文献链接仅为本地 query 参数，正文属性全部 HTML 转义；在 GET 单篇详情前验证 ID 属于本次文件夹 / 搜索结果，过期或伪造链接不显示其他范围文献。
- 原 PDF 通过原有接口打开；阅读中的原文页为原 PDF 渲染图。本轮未添加 PDF 批注 / 任意目录层级 / 拖拽，也未修改解析引擎与问答。
