## 5. 口径与限制

- **检索命中为自动文本匹配**（同篇 + 同物理页 + 金标准数值，或前三个 ≥5 字母词都出现），不是人工逐条判定；表格合并与跨栏切块会让命中偏保守。
- **回答判分为助手单次复核**（语义完整性口径，接受等价表达），不是双人盲审；逐题判定写入 `judgments.json`，可复核。
- **4 条标题待复核候选**（WisdoM 附录目录页、CMIR 数学花体标题等）按协议单独排除，未计入标题分母。
- **7 道不可答题**不进入检索指标，只进入回答成功率与拒答统计。
- 单次运行、单模型（DeepSeek Flash）、联网关闭；未做多次重复与置信区间。
- Recall@k 的分母是已标注的直接证据（非穷尽）；后续补齐标注时，Recall 会随分母变化。

## 6. 复跑

```powershell
# 1) 生产运行（付费；边跑边存，重跑跳过已完成题）
uv run python -m evaluation.collect_answers `
  --dataset evaluation/datasets/v0.3 `
  --out output/evaluation/production-v0.3-0.13.8 `
  --runtime output/evaluation/dataset-v0.3-0.13.8/runtime

# 2) 生成复核表，写 judgments.json 后评分（离线，不调用模型）
uv run python -m evaluation.score_production `
  --dataset evaluation/datasets/v0.3 `
  --run output/evaluation/production-v0.3-0.13.8 `
  --runtime output/evaluation/dataset-v0.3-0.13.8/runtime `
  --k 10 --review output/evaluation/production-v0.3-0.13.8/review.md
```
