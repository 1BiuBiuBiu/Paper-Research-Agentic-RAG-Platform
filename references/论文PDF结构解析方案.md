# 论文 PDF 结构解析方案与实测边界

核对：2026-10-21。原 PDF 是最终依据；结构化结果是可追溯的机器解释，不承诺所有版式无损重建。

## 为什么不能只抽 TXT

论文包含双栏顺序、标题层级、表头和合并单元格、图注 / 表注、公式、科学脚注、参考文献，以及页眉和出版附属信息。纯文本无法可靠保留这些关系。Markdown 适合阅读，但会丢失部分坐标 / 合并结构，因此不能作为唯一档案。

目标保存三层：原 PDF 与页面图；带稳定来源引用、坐标和父子关系的结构 JSON / 独立图表资产；适合按需检索的正文和带行列标签的表格片段。可读导出是派生物，不能覆盖原始信息。

## 成熟方案对照（官方资料）

| 方案 | 官方提供的相关能力 | 本项目取舍 |
| --- | --- | --- |
| Docling | 文档模型 / 序列化 / 分块；PDF 管线支持表格结构模式与单元格匹配 | 已锁定依赖，继续作为本机主链路；启用 ACCURATE 表格识别，保留引擎树和独立资产 |
| MinerU | 多种解析档位、OCR / 模型管线、统一结构输出及多种导出 | 作为复杂样本对照候选；本轮未安装、未运行，不据官方介绍宣称优于现有实测 |
| GROBID | 面向科技文献的结构化 TEI 与元数据 / 文献处理；提供元素坐标 | 可作未来书目 / 引文补强，不把 TEI 转换视为任意表格或公式精确恢复 |

## 当前修补

- 旧实现只保留 TextItem / Picture，且 do_table_structure=False；没有完整表格，不应称已验收表格解析。
- 开启 TableFormer ACCURATE。记录行列区间、表头角色、合并关系、单元格文字 / 坐标、表注与正文引用、原区域截图；结构和数值默认未人工核对。
- 保存 Docling JSON 的父子引用、组、原始结构与坐标。图像独立存储，JSON 使用占位而非重复嵌入二进制；Markdown 单独保存用于阅读。两者只通过所属论文的白名单导出。
- 保存阅读顺序中的文本 / 图 / 表引用；前页标题修正后仍保留引擎原始树作核对。UI 正文在对应位置显示研究图表区域，表格结构另有视图。
- 公式保存原区域和已抽文字，不把缺失 LaTeX 或未校验文本声称为精确公式恢复。扫描正文 / 公式模型 / VLM 需要独立资源和样本验证，本轮未启用。
- 通讯作者 / 邮箱 / 收修录用日期属于出版附属信息，原块 / 坐标仍在，但从正文和检索排除；有科学限定作用的脚注继续保留。
- 表格检索按行生成带表注 / 行号 / 列名的证据，保留表格定位。不能脱离表头给模型一串数字；缺失格不补猜。结构 JSON 和原表图始终可核对。
- 重新解析先校验原文 SHA256，暂存新资产；成功后快照旧记录、保留人工确认和匹配期刊的指标，事务切换；失败保持旧版本。规则刷新不会伪造旧记录已有新表格。

## 验证矩阵

| 内容 | 检查方法 |
| --- | --- |
| 双栏 / 顺序 / 科学脚注 | 原自建 3 页 PDF 的已标注顺序与排除项回归 |
| 数值与表头合并 | 新建 4 × 3 表格，金标准 0.731 / 0.704 / 0.812 / 0.793，横向与纵向合并分别核对，失败记录，不调夹具掩盖 |
| 原图与结构对应 | 表格图、来源页码、单元格坐标、JSON source_ref 与阅读流引用交叉核对 |
| 原论文 | 重新解析用户指出的两篇 PDF，记录表格 / 公式区域数，并抽查原区域和数值；不发送到第三方服务 |
| 失败保护 | 重新解析失败保留有效记录；人工字段、原文指纹和导出路径隔离测试 |

数值恢复、跨页大表、无边框 / 旋转表、嵌套标题、复杂公式与扫描件都可能失败。不得把模型成功返回等同于全部结构正确；保留问题清单，后续用相同样本比较候选引擎。
