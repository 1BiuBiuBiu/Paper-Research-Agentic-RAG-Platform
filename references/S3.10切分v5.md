# S3.10 切分 v5：段落优先 + 句边界 · 0.13.7 · 2026-10-23

用户要求：按段落切分；过长段落按句边界切；**单块 ≤800 字符**；**重叠 <150 字符且至少重叠一句话**。

## 规则与实现

| 项 | 值 |
| --- | --- |
| 单块上限 | `CHUNK_SIZE = 800` 字符 |
| 切分 | `sentences()` 按 `。！？；` / `. ! ?` + 空白切句；`windows()` 贪心打包到 ≤800 |
| 重叠 | 相邻块重叠**上一块的最后一整句**；该句 ≥150 字符时不重叠（保证 `OVERLAP_MAX=149` 与不超 800） |
| 超长单句 | 按 800 硬切 |
| 块间 | 一个解析块独立切分，不跨块合并 |
| 表格 | 仍是一行一个 chunk（不变） |
| 版本 | `CHUNK_VERSION = research-chunks-v5` → 所有索引需重建 |
