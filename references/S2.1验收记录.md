# S2.1 自建分类与论文移动

日期：2026-10-21。应用 0.3.0，分支 feat/s2-paper-categories，结构解析基线 50b5b9a。

## 完成与边界

- 单层自建分类，新建 / 重命名 / 数量统计；每篇归属一个分类，无归属为未分类。名称 NFKC / 空白规范化、忽略大小写查重，系统保留名 / 控制字符 / 过长输入拒绝。
- 论文库按分类和搜索筛选后分页，不是只筛当前页。可移动当前论文，或明确选择本页多篇后批量移动；API 最多 100 个 ID，重复 ID 去重。
- 移动在一个 SQLite 事务内先验证全部 ID / 目标分类；任一无效不移动任何论文。移回未分类使用显式 null。只改归属表，不搬动 PDF，不改解析 / 来源时间，不触发模型和重建。
- 空分类可归档 / 恢复；含论文时拒绝归档，不隐式搬走或删除论文。不存在永久删除入口。
- 问答可按分类筛选候选列表，仍显式选择单篇；没有将整分类或多篇问答冒充已完成。

## 存储与接口

SQLite schema v3 新增 categories / document_categories 与索引 / 外键；旧文档 JSON 不改写，未分类为无映射。category_id 为服务端派生信息，不允许借元数据更新伪造归属。初始化不降低更高 schema 版本。

- GET/POST /categories；PATCH /categories/{id}；POST /categories/{id}/archive 或 restore。
- POST /documents/move：document_ids + category_id（显式 null 表示未分类）。
- GET /documents 新增 category_id / uncategorized / q / include_samples；分类与未分类不能同时选，未知 / 归档目标明确拒绝。
