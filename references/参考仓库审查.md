## 可参考内容

项目包含 FastAPI、Streamlit、PDF 逐页分块、BM25/FAISS 混合检索、重排、LangGraph 改写循环以及评估/容器配置。这些适合做科研 RAG 方案起点，但 README 的能力和分数不能直接视为本项目已验证能力。
