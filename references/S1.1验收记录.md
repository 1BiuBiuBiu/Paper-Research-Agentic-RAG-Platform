# S1.1 论文来源一致性与工作台修复

日期：2026-10-21。应用版本 0.2.1，分支 fix/s1-paper-integrity-workbench，基线 28ca238。本次响应用户指出的实际数据错误和页面问题，不推进分类 / 多篇 / Agent 功能。

## 复现与证据

- 旧论文库表格仅展示，没有 on_select；点击表格行不会切换下方独立下拉选择器。详情可能仍为另一篇，且页面没有醒目的当前文件标识。自建样本摘要正是用户反馈中的两句话。
- 核对本机 SQLite：《Do LLMs Feel?》存储摘要实际为 ERC / PRC-Emo，与原始 PDF 一致，但尾部混入 Code / Extended Version 链接；没有发现其数据库摘要被自建样本覆盖的证据。
- CIEG-Net 首页原图显示顶部 Pattern Recognition 为刊头，下方才是论文标题；保留块 b2 被模型标为 title、b4 被标为 section_header，旧规则直接取首个 title。首页 A B S T R A C T 的字间空格导致摘要缺失，journal homepage 被误当期刊字段。
- 查看 f1 实际为 Elsevier 标志；f1–f5 是出版标志 / 小图标，真正 Figure 1 是内部 f6（第 4 页）。旧界面把所有图片按 fN 展示，混淆内部 ID 与原文图号。

## 修复与实际数据结果

- 刊头与主标题分离，支持空格标题 ABSTRACT、带作者标记 / 误标 section_header 的作者列表、摘要辅助链接边界；会议 AAAI-26 的年份按原文缩写识别，期刊年份取卷期行。
- CIEG-Net：标题 “CIEG-Net: Context Information Enhanced Gated Network for multimodal sentiment analysis”，期刊 Pattern Recognition，2025 年，3 位作者，摘要来源 b11，DOI / ISSN 保留。
- Do LLMs Feel?：4 位作者、AAAI-26 / 2026，摘要仅取 b6，不混入链接或样本内容，2 张研究图表。
- CIEG-Net 12 个图片区域全部保留：4 张有编号图注的研究图表、5 个装饰 / 图标、3 个待核对图像。默认仅展示 Figure 1–4，其他图像需显式展开。分类是图注 / 版面规则，不冒称已用视觉模型理解语义。
- 两篇真实论文和自建样本均先保存完整旧记录再应用规则；自建样本额外标记 is_sample 并在列表和问答中默认隐藏。没有提交用户论文、截图或备份到 Git。
- 备份：data/backups/20261021-004605-s1.1/library.sqlite3；每篇 data/papers/{id}/history/before-extraction-*.json。原文件 SHA256 与入库值一致。恢复需停 API 后结合整个 data 备份；不要用旧数据库覆盖后续新增记录。

## 验证

- 完整 pytest **54 passed，77.93 秒**，含真实 Docling / BGE，新增刊头 / 摘要 / 作者 / 图片分类、来源指纹拒绝、备份保留、人工字段保护、选择映射与编辑状态隔离测试。
- Ruff、mypy（46 个应用源文件）通过。AppTest 对真实 API 的原页预览 1 张、研究图表 4 张，未出现异常；首次工作区载入实测 4.5 秒，非性能承诺。
- 新版选择机制为 single-cell，提供默认高亮，并将 selection.cells 的行映射到唯一 document_id；不再需要另一个详情下拉选择器。浏览器实际点击 Do LLMs Feel? 单元格后，详情标题、10196-AAAI26.LiX-NLP.pdf 链接、9 页原页与 ERC / PRC-Emo 原始文字均切换到 f8dde709 记录。
- 浏览器论文信息页确认摘要字段为 ERC / PRC-Emo 原文，含 4 位作者与 2026；原文 / 解析页确认同一文件的真实首页与文字并排显示。截图保存在忽略的 output/pdf/s1.1-workbench.png。
- 未调用 DeepSeek / VLM 或联网元数据服务；真实生成仍待服务端 Key。第三方 TestClient 弃用提示保留。

## 限制

真实样本覆盖增加到本轮反馈的两篇，仍不能推断任意期刊模板均正确。无编号图注的图片保持待核对，不静默删除；人工确认字段不会被规则覆盖。更新来源使旧索引失效，需要重新建立。UI 美观仍需用户体验验收，后续修改继续按切片记录与提交。
