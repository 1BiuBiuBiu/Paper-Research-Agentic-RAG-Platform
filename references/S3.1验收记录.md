# S3.1 项目对话与输入框选模型验收

2026-10-21；应用 0.5.0，分支 feat/project-chat-composer，基线 673940e。

## 用户要求与交付

用户要求参考 Codex：模型在对话输入区直接选择，左侧可建立项目并组织对话。输入区位置参考 [OpenAI 官方模型选择说明](https://learn.chatgpt.com/docs/models#choose-a-model)；项目组织依据用户明确要求，不将产品原有仓库 / worktree 能力照搬成科研文献目录。

- Agent 左侧新建项目、项目列表 / 项目内对话、未分组；项目和对话可改名，对话单归属移动，空项目可归档 / 恢复。
- 底部输入框下方直接选具体模型，展示模型 ID / 服务商，同名模型身份隔离；资料范围入口并列。设置分模型 / 服务商，持久保存新对话默认模型。已有成功对话沿用上一轮模型，停用时要求重新选择。
- 原有主导航、论文库、浅色蓝色主题、连续追问和引用保留；不将项目等同论文文件夹，不复制论文，不隐式检索项目资料。
- 密钥仍只在服务端读取；没有凭据输入 / 回显和自动付费调用。当前仅 Chat Completions 兼容服务；没有自动模型发现或虚构推理强度控制。

## 文件与数据边界

- domain/projects：项目输入、显式对话更新和默认模型输入。
- repositories/project_schema / projects / conversations：schema v5、项目唯一名、归属外键 / 索引、事务改名 / 移动、归档恢复；conversations 改为显式列插入。
- repositories/connections、providers/registry：默认选择元数据和模型目录，无模型网络请求。
- routes/projects / agent 与 api：项目、目录 / 默认选择、对话过滤 / 归属更新。
- ui_components/chat_navigation / model_picker / agent / settings / theme：项目导航、单个模型选择器、底部输入区和管理页签；模块均小于 400 行。
- tests/test_projects / test_agent_ui / test_qa_scope：迁移、事务、模型身份 / 默认 / 停用、真实组件交互与 schema 预期。
- PRD / 架构 / 状态 / CHANGELOG / README 和根应用版本同步，无依赖升级。

## 实际验证与证据

- v4 旧库迁移保留标题 / 文档 / 未分组；新旧应用重启后项目与消息 / 默认选择保持。
- 项目创建、名称唯一 / 空白 / 长度验证；未知或归档项目拒绝，非空项目归档拒绝，空项目归档后可恢复。
- 单对话移动 / 改名保持原 turn / revision，失败不部分改名；列表按项目 / 未分组隔离，混合冲突条件拒绝。
- 不同服务商的同名模型不混淆；默认模型白名单 / 停用验证；选中服务被停用时输入禁用且不回退内置模型。
- AppTest 使用 RecordingProvider / MockTransport，真实组件操作覆盖项目建对话 / 移出项目、连续消息 / 范围、失败重试、模型默认表单及停用不回退。没有外部模型请求。
- 真浏览器：127.0.0.1:18501 / API 18000，RESEARCH_DATA_DIR=tmp/project-ui-smoke。通过侧栏创建“界面验收 · 情感识别”，项目内新建对话，输入框下直接切到 deepseek-v4-pro；没有发送问题。临时实例验收后停止，测试记录未进入实际库。
- 主平台 8501 实际页面核对输入区完整显示，模型与服务商管理页签；主平台保持运行，原论文页未导航 / 编辑。证据在忽略的 output/pdf/s3.1-agent.png、s3.1-project-test.png、s3.1-models.png。

初次页面检查发现固定输入区沿用框架 100% 宽度造成右侧裁切，已明确按视口减去侧栏 / 边距计算宽度并在新服务进程核对。默认模型表单初次选择时按钮不能依赖尚未提交的值禁用，改为只在无模型可选时禁用，并有首次选择提交回归。

最终 pytest -q：84 passed / 4 skipped，34.34 秒，4 项既有第三方弃用警告；Ruff / 格式 101 文件、mypy 75 源文件、compileall、uv pip check（137 包）与 uv lock --check（136 包）均通过。实际服务返回 0.5.0，项目 / 默认选择未被验收改动，外键检查正常，4 份原 PDF SHA256 与记录匹配。
