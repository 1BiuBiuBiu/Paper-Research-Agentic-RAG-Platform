# S3.0 持久会话、多篇 / 文件夹范围与模型连接

日期：2026-10-21。应用 0.4.0，分支 feat/s3-conversation-workspace，页面基线 d266a14。

## 本轮范围

用户明确要求：左主导航为论文库与 Agent 平台；论文库内左文件夹 / 右文献；Agent 平台提供类似会话工作台的持续对话，可选择任意多篇论文或一个文件夹，模型 API 不能固定 DeepSeek。

- 左主导航已实现；Agent 页为对话记录 / 新建、模型服务 / 资料范围 / 对话选项、消息流和底部输入。新建、改名、查看与较早对话分页；失败轮次可手动重试，历史 / 引用持久保存。
- 范围模式为显式多篇、文件夹 / 未分类或显式通用对话；跨分类选论文不改变论文归属。最多 100 篇，全部文献 / 索引有效后才问答；空 / 未知范围不回退全库。
- 文件夹按每轮服务端快照解析，范围和实际上下文覆盖分开显示。最多 10 段、24000 UTF-8 字节证据，不默认发送全文，不承诺通读所有选中文献。
- 同实际文档集合 / 来源版本最近最多 6 轮连续历史，每轮问题 / 回答分别最多 800 / 1200 字节；历史引用替换为历史标记，不能冒用本轮引用。范围变更不删除旧消息，但不把旧范围历史发给新范围。
- 连接可新增 / 编辑 / 停用，配置 Base URL、模型列表、密钥环境变量名、是否需要 Key 和 JSON 参数能力。当前为 Chat Completions 兼容协议，其他协议须另适配；内置 DeepSeek Flash / Pro 与旧 /query 保持。

## 工程与安全

- schema v4 新增 conversations / conversation_turns / model_connections；原文档 JSON / 分类表 / PDF / 解析 / 索引不改写。主分层为 domain/agent、repositories、providers/registry、services/agent_scope / agent_answer / conversations、routes/agent 与 UI agent / settings。
- 同对话 BEGIN IMMEDIATE 验证 request_id / expected_revision / pending，再释放数据库锁执行模型请求，成功原子持久化与递增 revision；失败只记失败，不存假答案。相同已成功请求返回缓存结果，不再次调用；ID 内容冲突、过期 revision 或并发请求明确拒绝。
- 重启将 pending 标为 interrupted，可手动重试。服务中断可能发生在供应商已计费后，无法提供跨供应商 exactly-once 保证，所以没有自动外部重试。
- 通用兼容 payload 不带 DeepSeek 的 thinking / reasoning_effort；复用总超时、输出大小 / 结构限制、凭据回显拒绝、状态映射与不跟随重定向。配置保存不自动联网；configured 仅说明本机密钥条件满足。
- Key 只读服务端 RESEARCH_MODEL_KEY_* 专用变量或 .env；数据库保存变量名，无浏览器 Key 输入和数据库 Key 值。外部 HTTPS / 本机 HTTP，禁止 URL 凭据 / 参数 / 片段，模型名必须来自该连接白名单。
- 原有解析 / 向量 worker 的环境过滤新增 MODEL_KEY，保证新命名的服务密钥也不传给这些子进程；两项原有子进程边界测试已扩充断言。解析模型和分块输出规则未改。
- 模型文本纯文本展示；原文链接由本轮实际证据 ID / 文档 / 页码构造。回答后再验证文件夹成员与来源版本，变化则本轮失败，防止旧范围回答被保存为新范围结果。

协议依据：[DeepSeek Chat Completions 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/)；保留 user / assistant 历史消息与结构 JSON 输出，真实供应商差异仍需各连接实际验收。

## 实际验证

- 快速测试 **77 passed / 4 skipped，24.97 秒**。最终会话 / 接口 / UI 专项另回归 9 passed。跳过真实 Docling、TableFormer、BGE 模型四个显式项，原有纵向合并缺陷仍存在；没有真实付费模型调用。
- 新增 6 项 API 集成测试：两篇范围与一次问题编码 / 第三篇隔离、连续追问 / 重启持久化 / 幂等缓存、文件夹成员变化与历史隔离 / 生成中变化拒绝、空 / 未知 / 未就绪 / 样本范围拒绝、pending / 并发 / 请求冲突 / 中断恢复 / 手动重试、自定义服务地址 / 模型 / 专有参数隔离 / Key 不回显 / 禁用 / 不合规 URL 与免 Key 本机接口。
- 新增 3 项 AppTest：跨文件夹两篇选择与连续两轮 / 文件夹选择 / 离开再恢复，失败轮重试仍只一条记录，设置新增连接并由 Agent 选择，缺 Key 时禁止发送。回答和远程传输使用明确的 RecordingProvider / MockTransport，不冒充真实 LLM 验收。
- 首轮自动标题与响应保存在同一事务，人工在生成期间改名不被自动标题覆盖；对应并发回归通过。连接 URL 在 domain 使用标准库校验，不引入 HTTP 层依赖。
- Ruff / 格式 94 个文件、mypy 69 个应用源文件、compileall、uv pip check（137 包）、uv lock --check（136 包）通过。保留 TestClient/httpx 及测试客户端 timeout 的既有弃用警告，不为此擅自升级。
- 实际 API 版本 0.4.0；只读复核 3 篇真实论文原件 SHA256，文档 JSON 和分类归属与 before-agent-smoke 一致性快照相同。该快照在新增表初始化后、实际 Agent 页面验收前保存，不声称是迁移前备份；已有更早快照继续保留。后续 pytest 将默认实例引导数据指向 tmp/test-bootstrap，测试夹具仍使用独立临时库。
- 实际浏览器验收左主导航、论文库、Agent 资料选择与模型设置；当前没有已配置密钥，发送框明确禁用，未发真实模型问题。用户当前导入页保留，独立浏览器标签用于验收；截图 output/pdf/s3.0-agent.png / s3.0-library.png（忽略，不入 Git）。
- 实际跨文件夹多选 CIEG-Net 与 Do LLMs Feel?，有效范围为 2 篇；整未分类文件夹解析为 3 篇。设置有名称 / Base URL / 任意模型列表 / Key 变量引用表单，未创建假连接或真实付费消息。论文库截图也补存为 output/pdf/s2.1.2-library.png，布局沿用 d266a14，拍摄时运行版本为 0.4.0。
