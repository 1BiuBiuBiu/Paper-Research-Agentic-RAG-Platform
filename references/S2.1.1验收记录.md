# S2.1.1 文献文件夹工作台

日期：2026-10-21。应用 0.3.1，分支 feat/s2-library-folders，基线 71b7335。

## 需求与范围

用户明确要求参考 Zotero 管理文献、初始不展示具体结果、每篇有独立子文件夹并可移动，尽量避免多处出现。按其最新要求确定单分类归属，替代 PRD 早期多类别表述。参考 [Zotero 布局](https://www.zotero.org/support/quick_start_guide)及[集合说明](https://www.zotero.org/support/collections_and_tags)，仅借鉴管理交互，归属规则遵从用户要求。

- 左侧分类文件夹与数量，中间文献列表；可新建 / 管理分类。分类较多时独立滚动，不让目录挤出整个导航。
- 默认没有当前论文，首次进新布局时旧会话选择清空。点击论文后打开专属文件目录，含原始 PDF / 解析内容 / 图表附件及可用结构导出入口；选择具体视图后才读页面图片或解析结果。
- 切换分类 / 搜索 / 页码 / 演示样本、重新进入论文库、关闭 / 取消表格选择均清空旧详情；再开论文回文件目录，不继承另一篇或上次的阅读结果。
- 每篇入库已经自动创建 data/papers/{document_id}/，本轮复用这一存储。原件 original.pdf、版本化解析资产和 history 快照共同归属唯一文献。分类移动仍为原子关系更新，文件和索引位置不变；无需迁移现有用户数据。
- 全部论文是汇总视图，不是新增归属或文件副本；内容 SHA256 去重，相同 PDF 改名上传仍返回原 ID / 原目录 / 原分类。新文献先进入未分类，用户自行移动。

## 修改范围

- UI：library、categories、theme、detail、folder_contents；不更换 Streamlit 或浅色蓝色主题。
- 列表契约：DocumentSummary / PaperRepository 新增 authors，只派生已有元数据，无 schema 迁移。
- API / 项目版本更新至 0.3.1，uv.lock 仅根项目版本变化，依赖版本不变。
- tests/test_ui_integrity、test_paper_integrity、test_ingestion、test_categories，PRD / 架构 / 状态 / README / CHANGELOG 同步。
